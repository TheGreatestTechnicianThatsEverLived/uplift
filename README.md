# 🎯 Uplift-моделирование


## 📌 О проекте

**Тема:** 86. Uplift-моделирование

**Задача:** Разработать модель, которая точно прогнозирует прирост вероятности сделки клиента после воздействия (Uplift). Это позволит таргетировать рекламные коммуникации только на те группы клиентов, которые положительно отреагируют на них, исключая «бесполезные» контакты с теми, кто купит и так (лояльные) или не купит никогда (потерянные), тем самым оптимизируя маркетинговый бюджет.

**Уровень сложности:** middle

**Пререквизиты:** Pandas, NumPy, Matplotlib, Scikit-learn

**Стек технологий:** CausalML, EconML, Scikit-uplift, AUF

## 🔬 Задачи проекта

1. **Сбор и подготовка данных** — получение исторических данных о маркетинговых кампаниях (воздействие, признаки клиентов, факт отклика).
2. **Разведочный анализ данных (EDA)** — изучение структуры, визуализация, выявление закономерностей.
3. **Дизайн эксперимента** — подтверждение корректности проведения кампании (контрольная и тестовая группы).
4. **Выбор и реализация методов моделирования:**
   - Классические подходы: S-Learner, T-Learner, X-Learner.
   - Современные подходы: Causal Forest и другие.
5. **Оценка качества модели** — специализированные метрики для Uplift-моделирования (AUF, Qini и др.).
6. **Интерпретация результатов** — выделение групп «убеждаемых» (высокий predicted uplift) и «не беспокоить» (отрицательный uplift).
7. **Разработка сервиса** — реализация ML-сервиса на FastAPI.
